Mega Man (NES), Celeste-style: checkpoints, a death counter, L/R weapons.

The ROM is not included. Put your "Mega Man (USA)" NES ROM next to the
program, named megaman.nes or "Mega Man (USA).nes" (the .nes file, not a
.zip), then open the program. You can also drop the .nes file on it, or run:

    megaman path/to/rom.nes

Saves go to the saves/ folder next to the program.

Keyboard: arrows, Z = B (fire), X = A (jump), A = rapid fire,
Enter = Start, Right Shift = Select, Q / W = previous / next weapon,
Esc = menu. A gamepad works too (Xbox layout; Guide button = menu).

Windows: SmartScreen may warn about an unknown program: More info > Run anyway.
macOS: the app is not signed by Apple. The first time, right-click megaman >
Open, or run in Terminal:  xattr -dr com.apple.quarantine <this folder>
Linux: needs SDL2 (Debian/Ubuntu: sudo apt install libsdl2-2.0-0).

CRT overlays (menu > OVERLAY): "perfect_overlays" by ourigen,
https://github.com/ourigen/perfect_overlays (credits: 1playerinsertcoin,
mugwomp_93, drkhrse).
